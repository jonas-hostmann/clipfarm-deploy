ℹ️ Wie es funktioniert

1. Trage deinen OpenRouter API Key ein und wähle ein Modell.

2. Beim Speichern wird der Key in der Datenbank gespeichert.

3. Wenn Coolify verbunden ist, werden die Env Vars automatisch aktualisiert und SupoClip restartet.

4. SupoClip nutzt dann OpenRouter für alle KI-Operationen (Virality-Scoring, Hook-Generierung, etc.).
